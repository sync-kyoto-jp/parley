# Parley — Google Play データセーフティ 申告ガイド

最終更新日: 2026-06-04

このドキュメントは、Play Console の「**データセーフティ**」フォームに入力するための回答案と根拠です。
Parley の実際のデータの流れに基づいています。最終的な申告内容はご自身でご確認ください。

---

## 0. 前提（Parley のデータ実態）

- **開発者サーバーは存在しない**（開発者はユーザーデータを受信・保存しない）。
- **BYOK**：ユーザーが入力した OpenAI API キーは **端末内に暗号化保存**（Android Keystore）。開発者へは送られず、OpenAI への認証にのみ使用。
- **マイク音声**：翻訳セッション中のみ取得し、**端末から OpenAI へ直接送信**（TLS）。アプリは音声を保存しない。
- **翻訳テキスト（会話履歴）**：**端末内にのみ保存**。外部送信なし。アプリ内で削除可・アンインストールで消去。
- **広告・解析（アナリティクス）・トラッキング・クラッシュ収集：なし**。

## 1. トップレベルの質問

| 質問 | 回答 | 補足 |
|---|---|---|
| アプリはユーザーデータを収集または共有しますか？ | **はい** | 音声を翻訳のため OpenAI へ送信（＝端末外へ送信）するため |
| 収集するすべてのユーザーデータは転送中に暗号化されますか？ | **はい** | OpenAI との通信は TLS（wss/https） |
| ユーザーはデータの削除をリクエストできますか？ | **はい（端末内で完結）** | 開発者保有データなし。会話履歴・APIキーはアプリ内で削除でき、アンインストールで全消去 |

> 「データ削除」について：Parley は開発者側にデータを保持しません。アプリ内の削除機能とアンインストールで端末内データを消去できます。OpenAI へ送信された音声の取り扱い・削除は、ユーザー自身の OpenAI アカウント／OpenAI のポリシーに従います。

## 2. 申告する「データの種類」

### 音声ファイル → 音声（録音）／Voice or sound recordings

| 項目 | 回答 | 根拠 |
|---|---|---|
| 収集する | **はい** | マイク音声を翻訳のため OpenAI へ送信（端末外へ出る＝「収集」に該当） |
| 共有する | **いいえ（推奨）** ／ または はい | 下記「共有の判断」参照 |
| この種類のデータは必須か（ユーザーが収集をオフにできるか） | **必須** | 音声がないと翻訳という中核機能が成立しないため |
| 目的 | **アプリの機能（翻訳）** | 広告・解析等には一切使用しない |
| 一時的にのみ処理されるか | **いいえ（保守的に「収集」として申告）** | アプリは保存しないが、OpenAI 側で不正監視等のため一時的に保持される可能性があるため、ephemeral 扱いにはしない |

#### 共有の判断（「共有する」を「いいえ／はい」どちらにするか）
- **推奨：いいえ** — OpenAI は「翻訳機能を提供するためにデータを処理するサービスプロバイダ」と位置づけられ、Google の定義では service provider への提供は「共有」に当たらないと整理できます。OpenAI への送信はプライバシーポリシーで明示済みです。
- **代替：はい（OpenAI）** — より透明性を重視する場合は「第三者（OpenAI）と共有」と申告しても構いません。
- どちらを選んでも **プライバシーポリシーに OpenAI への送信を明記**してあることが前提です（記載済み）。

## 3. 申告「しない」もの（理由つき）

| 項目 | 申告 | 理由 |
|---|---|---|
| OpenAI API キー | しない | 端末内に暗号化保存される「資格情報」。開発者へは送られず、OpenAI への認証にのみ使用。Google のデータ種別に該当しない（※プライバシーポリシーには記載済み） |
| 翻訳テキスト・会話履歴 | しない | **端末内にのみ保存**し外部送信しない＝Google の定義で「収集」に当たらない |
| 位置情報 | しない | 取得しない |
| 連絡先・カレンダー | しない | 取得しない |
| 写真・動画・ファイル | しない | 取得しない |
| 財務・健康情報 | しない | 取得しない |
| メッセージ | しない | SMS等は扱わない |
| 端末ID・広告ID | しない | 取得しない（広告・解析なし） |
| アプリのアクティビティ／パフォーマンス（解析・クラッシュ） | しない | 解析SDK・クラッシュ収集を導入していない |

## 4. 早見表（フォーム入力用）

- データを収集/共有する：**はい**
- 転送中の暗号化：**はい**
- 削除リクエスト手段：**あり（端末内：アプリ内削除＋アンインストール）**
- 申告する唯一のデータ種別：**音声（録音）**
  - 収集：はい／共有：いいえ（推奨）／目的：アプリの機能／必須
- 解析・広告・トラッキング：**なし**

## 5. 注意・将来の変更が必要になるケース

以下を導入したら、データセーフティの再申告が必要です。
- 解析（Firebase Analytics 等）／クラッシュレポート（Crashlytics 等）→ 「アプリのアクティビティ」「診断」等の申告が必要
- 自前バックエンド（マネージド型へ移行）→ サーバーでの収集・保持の申告が必要
- アカウント機能・課金 → 個人情報・購入履歴等の申告が必要
- クラウドへの会話履歴同期 → 「メッセージ」等の収集・共有の申告が必要
